# 饭饭小地图 Implementation Plan

**Goal** 完成深圳个人美食微信小程序及公开源码交付。
**Architecture** 微信原生页面通过统一云函数读写个人数据，照片存储在微信云存储，路线由云端腾讯地图适配。
**Tech Stack** JavaScript、WXML、WXSS、微信云开发、WechatSI。
**Spec** docs/superpowers/specs/2026-11-12-food-map-design.md

## Global Constraints
中文界面，深圳初始区域，可爱手绘配色。身份来自云端 OPENID。凭据通过本地配置与云函数环境变量设置。

## Review Focus
- 拒绝越权读取和更新。

- 无路线时显示服务反馈。
